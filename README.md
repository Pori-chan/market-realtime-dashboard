# ライブマーケットダッシュボード

React、TypeScript、Finnhub WebSocket API で構築した、米国株式市場向けのリアルタイムダッシュボードです。

![screenshot](docs/screenshot.png)

## 主な機能

- WebSocket によるリアルタイム取引ストリーム
- カスタムウォッチリスト
- 銘柄シンボル検索
- リアルタイムのスパークラインチャート
- ツールチップ付きの拡大チャート
- 英語 / 日本語の表示切り替え
- デモモード
- レスポンシブレイアウト

## 技術スタック

- React
- TypeScript
- Vite

- Finnhub API
